二、RSA

  • n = p × q，φ(n) = (p − 1) × (q − 1)，e × d 对 φ(n) 的余数是 1
  • 加密 c = m^e mod n；签名 s = m^d mod n
  • 公开 n、e；保密 p、q、φ(n)、d
  • m ≥ n 不能直接加密
  • 核对：公钥 (55, 3)，明文 18 → φ=40，d=27，密文 2
  • 核对：p=47，q=71，e=3 → n=3337，φ=3220，d=2147

口诀（RSA 能否直接加密）：明文必须小于模数，大于等于 n 就先分块。

口诀（密钥方向）：公钥加密用私钥解，私钥签名用公钥验。

口诀（流密码密钥流）：同一密钥流用两次，密文相异或就露出明文差。a 的 ASCII = 97 = 01100001。

口诀（iptables 黑白名单）：默认放行是黑名单，默认拒绝才是白名单。

口诀（iptables 三链）：进看 INPUT，出看 OUTPUT，穿过防火墙看 FORWARD。

四、流量与主机

  • 开放：SYN/ACK。关闭：RST 或 RST/ACK
  • 过滤：ip.addr == 地址 && tcp.dstport == 端口
  • Linux：ll≈ls -l；644=rw-r--r--；../ 父目录；md5sum / sha256sum
  • Windows：eventvwr.msc；firewall.cpl；4624 成功，4625 失败

口诀（端口扫描回包）：开放端口回 SYN/ACK，关闭端口回 RST。

五、场景关键词

  • 8750 → 5k–10k = 泛化；抹掉 = 抑制；薪水 = 属性隐私
  • 题干四级（公开/内部/秘密/机密）时，员工个人信息的常见写法是三级秘密数据。题干用数安法三分法时，改写一般 / 重要 / 核心
  • 过度采集：网络安全法、数据安全法、个人信息保护法
  • Android：签名 META-INF，权限 AndroidManifest.xml，Content Provider 易泄漏，默认无 root
  • SQL 注入：参数化查询。命令执行：禁止把输入送进 system/exec

口诀（脱敏手法）：精确值改成区间叫泛化，直接抹掉字段叫抑制。

口诀（Android 泄漏点）：签名在 META-INF，权限在 Manifest，内容提供者最易漏。

口诀（SQL 注入防护）：参数化查询先编译，用户输入不当成语句。
