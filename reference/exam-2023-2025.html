2023–2025 考点分布（非官方成套真题）

用于校准「课会不会太浅」· 2026-08-24 整理 · 不替代 2018–2022 官方试题分析

先看这一条：清华社指定用书《信息安全工程师 2018 至 2022 年试题分析与解答》（ISBN 9787302671176，2024-08）是目前唯一官方成套解析，目录只到 2022 下半年。
2023 年起全面机考抽题：不同批次题目不完全相同，官方不公布完整卷。下面内容来自信管网等培训站点的公开题干/考点帖，一律标成机考回忆 / 二手来源。用来看「还考什么、下午怎么出」，不算标准答案、不拿来估官方通过率。

一、机考后对备考意味着什么

2018–2022（纸笔 / 官方成套）2023–2025（机考）
能不能刷「整套原卷」可以，以清华社试题分析为准没有官方整卷；题库抽题，死记某套回忆卷收益有限
题型有没有变上午 75 单选 + 下午 4–5 案例题型没变；英文题仍约 5 道，近年阅读更长
大纲2020 审定版仍是 2020 审定版，教程仍是第 2 版 26 章
课该不该加厚—不必把课写成大学讲义；要补的是国密参数、网闸、等保流程、iptables 命令、案例模板

二、上午卷：这三年在考什么

和 2018–2022 比，骨架没换（密码、防护、系统、管理），但机考后更爱考「教材原句 + 标准条款 + 国密数字」。

知识块机考后仍高频对你已学 / 未学的含义
等保 / 法律 等级保护工作环节（定级 / 备案 / 等级测评 / 运维）；《网安法》第 21 条「国家实行等级保护」 第 1–10 课几乎没覆盖 → 后续课必须上
国密 SM1/SM2/SM3/SM4/SM9/ZUC 的「对称还是杂凑」；SM1 分组与密钥长度（公开回忆题给的是 128/128） 第 3 课只点了名字 → 密码课要补一张参数表，不必推数学
协议 SSH 子协议（传输层负责算法协商与密钥交换）；Kerberos 的 KDC = AS + TGS 第 4 课偏证书/HTTPS → 后续补安全协议对照
防护设备 防火墙 vs 网闸（物理隔离强度、是否对外开端口）；蜜罐四种配置（2023 公开考点） 网闸在教材第 11 章，课还没上；蜜罐已在第 10 课
访问控制 / 标准 访问控制操作辨析；GB 17859 哪一级开始要审计；等保「可信验证」 访问控制、测评标准都在后半程
恶意代码 宏病毒载体（如 Melissa 与 Word）——仍是「关键词对应」题 第 9 课风格一致，课不浅，是题就这样
英文题 2025 公开回忆为较长生物特征认证（biometric）阅读填空，不只有 firewall/VPN 单词 继续积累术语；临考练一篇长英文比多背单词表更值

上午公开题干来源示例： 信管网 · 2025 综合知识（更新中） · 信管网 · 2023 蜜罐四种配置

三、下午卷：过线关键，课里必须加「写法」

机考后下午仍然是「给拓扑 / 给日志 / 给命令，填设备名、模型名、一条 Linux 命令」。和上午的「认概念」比，这才是你觉得课太浅时真正缺的东西。

案例套路反复出现的得分点
等保 + DMZ + 边界 网闸（近物理隔离）、屏蔽子网、防火墙第几道防线、网站在 DMZ / 库在内网
Linux 防火墙 iptables 的 filter 表；默认 ACCEPT = 黑名单思路；iptables -P INPUT DROP；放行 22/80/443
IDS/IPS 主动/被动、P2DR 四要素、误用 vs 异常、Snort 三种模式（嗅探 / 记录 / 网关）
密码应用 DES 分组填充、S 盒查表、异或与流密码——考「会填」，不考证明
主机 / Web / 移动 Web 木马文件、Linux 哈希工具、Android 四大组件与签名目录（考生回忆，批次间差异大）
和你已学内容的关系：第 5–6 课的屏蔽子网、IDS/IPS 辨析，下午会原样再考一遍，但会要求你写出设备名和命令。不是课讲错了，是还没练「答题格式」。

下午来源需交叉看：信管网部分「2023 演练」与 2022 官方下午题高度相似，可能是旧题当模拟。以清华社 2022 下午卷练手型，再用回忆帖补网闸/安卓等新面孔。

四、这三年分析之后，课程怎么改（已定）

  1. 计分用官方 2018–2022 整卷：能对答案、能算 45 分线。这是「能不能过」的唯一可靠尺子。
  2. 2023–2025 只进「考点清单 + 课内 1 道原句风格题」：不整卷抄进 HTML（无官方原文，且版权/对错都无法保证）。
  3. 从第 11 课起优先补这张表里标红的缺口：风险评估、等保流程、应急、网闸、国密参数表、iptables 模板。
  4. 考前 2 周：用软考官网机考模拟练习熟悉界面（只练环境，题量/分值以正式系统为准）。
