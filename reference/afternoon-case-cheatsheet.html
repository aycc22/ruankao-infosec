第 23 课配套 · 云 / 工控 / 移动 / 大数据场景 · 打印用

一、万能答题骨架（5 步）

  1. 判场景：云 / 工控 / 移动 / 大数据 / 混合
  2. 列风险：3–5 条，「现象 → 后果」
  3. 写对策：与风险成对，每条一行
  4. 叠合规：等保通用 + 对应扩展；跨境/个保等特殊要求
  5. 收束：监测审计 + 应急预案

下午卷案例答题模板：先判场景列风险，对策成对写一行，合规扩展别漏项，监测应急来收束。

二、安全工程五阶段

需求分析 → 安全设计 → 实施建设 → 测评验收 → 运维保障

安全工程五阶段：先分析后设计，实施测评再运维（字头：分设实测评运）。

三、四场景对策素材库

场景风险关键词对策关键词（任挑组合）
云计算 逃逸、多租户越权、数据残留、API 滥用、中断 责任共担；VPC/安全组；租户隔离；加密+KMS；安全擦除；镜像加固；等保云扩展

五、全局易错（案例里别写反）

  • 等保测评 ≠ 风险评估（测评=符合性；评估=算风险）
  • 工控优先序：可用 > 完整 > 机密
  • 脱敏 ≠ 加密；抑制 ≠ 泛化
  • 私钥签名 → 公钥验签
  • 敏感令牌勿明文存移动本地
