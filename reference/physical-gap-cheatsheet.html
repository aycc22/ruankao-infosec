物理安全与网闸速查

依据《信息安全工程师教程（第 2 版）》第 5、11 章 · 打印用

一、物理安全三块

  • 物理防护：机房选址、建筑结构、门禁、监控、防盗、防火、防水、防静电
  • 电磁与介质：TEMPEST 电磁泄漏 → 屏蔽、干扰；介质销毁 → 消磁、物理粉碎；报废须清数据
  • 环境保障：温湿度、UPS、防雷、消防（气体灭火等）

机房物理防护要点：选址结构把门禁，监控防盗防火水，静电也要防。

机房门禁与访客：生物识别配 IC 卡，双因子进门，访客登记须陪同。

二、TEMPEST 与销毁

题干选别选
电磁泄漏 / TEMPEST屏蔽、干扰加密、防火墙、VPN
报废硬盘 / 信息残留消磁、物理粉碎 + 清数据只删文件、只格式化、直接扔掉

电磁泄漏防护 TEMPEST：防电磁泄漏靠屏蔽，干扰可辅助，加密防火墙帮不上。

存储介质销毁：报废先清数据，消磁粉碎才算毁。

机房环境保障：温湿度要稳，UPS 保电，防雷气体灭火。

三、网闸 Gap

内外网不直连；数据单向或受控摆渡。相关实现：双网卡隔离、光单向导入。强度高于防火墙逻辑隔离。

物理隔离与网闸：内外网不直连，网闸摆渡或单向，强度高于防火墙。

四、设备辨析

技术性质秒判
网闸物理 / 近物理隔离不直连；摆渡/单向；不对外开端口
防火墙逻辑隔离规则过滤；可开端口；双向会话
VPN加密隧道保密传输，不是隔离
IDS检测旁路告警，不隔离
IPS逻辑阻断串联可挡，仍非物理隔离

网闸与防火墙辨析：防火墙逻辑可开端口，网闸物理不直连；VPN 加密不隔离，IDS 只看不隔离。

五、等保与工控挂钩

  • 等保技术五大类第一项：安全物理环境（GB/T 22239）
  • 工控边界：工业防火墙 / 工业网闸 / 单向隔离；电力横向隔离接近物理隔离
  • 下午卷拓扑：近物理隔离 → 填网闸；网站 → DMZ；库 → 内网

等保物理环境定位：技术五大类第一项，就是安全物理环境。

六、易错陷阱

  • 双重宿主主机（双网卡防火墙结构）≠ 网闸
  • 删文件 ≠ 介质销毁
  • TEMPEST ≠ 加密
  • 网闸隔链路，不保证文件里没有恶意代码
  • 等保测评 ≠ 风险评估

七、英文词汇

Physical security · TEMPEST · Shielding · UPS · Degauss · Physical destruction · Network gap / Gap · Ferry / one-way transfer · Physical isolation vs logical isolation

八、下午卷模板

先写门禁监控 + 介质销毁 + UPS/消防 → 再写网闸不直连/摆渡 → 防火墙/VPN 只作逻辑补充 → 点名等保安全物理环境。
