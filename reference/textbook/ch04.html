4.1–4.2 安全体系

  • 安全体系 = 技术 + 管理 + 工程，分层防御（纵深防御 Defense in Depth）。
  • PDRR 模型：Protection 防护、Detection 检测、Response 响应、Recovery 恢复。

4.3–4.5 经典安全模型（上午卷选择）

  • BLP 模型（Bell-LaPadula）：侧重机密性，不上读不下写（No Read Up, No Write Down）。
  • Biba 模型：侧重完整性，不上写下读（No Write Up, No Read Down）。
  • Chinese Wall 模型：防利益冲突，动态访问控制。
  • Clark-Wilson 模型：完整性，事务处理与职责分离。

4.4 访问控制模型关系

  • 自主访问控制 DAC、强制访问控制 MAC 与 BLP/Biba 密切相关。
易错陷阱：
BLP=机密性，Biba=完整性，别搞反。
PDRR 四个阶段顺序常考。
