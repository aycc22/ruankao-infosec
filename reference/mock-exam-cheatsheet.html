二、一场怎么坐

科目做法
上午 75 单选 站点口径：两科连考共 240 分钟；科目一最长 120、最短 90 分钟（考试全貌）。练习可先压到 100–110 分钟找手感。
下午案例 按「风险 + 对策」成对写（第 23 课）。拓扑 / iptables 回第 28 课。
卡住 先标记跳过，会做的分先拿到，回头再补。

计时模考为何现在上：知识点已经学完，要在限时压力下把答案从脑子里捞出来，才能变成考场分数。

上午限时手感：科目一在站点口径里最长一百二十分钟、最短九十分钟，练习可先压到一百分钟找手感。

卡住先跳再回头：不会的先标记跳过，把会做的分先拿到，别在一题上耗光整卷时间。

下午卷仍按风险对策：案例题先列风险再写成对对策，不要只堆设备名词。

四、薄弱清单（每次模考后过一遍）

  • 密钥方向：公钥加密 → 私钥解密；私钥签名 → 公钥验签
  • 等保测评 ≠ 风险评估
  • 日志半年 → 网安法（现行第 23 条）
  • 三法分工：日志/等保/关基 → 网安法；分类分级 → 数安法；同意/敏感 → 个保法
  • 行三人列俩货：能力、前缀、口令 / ACL、保护位
  • DMZ 在屏蔽子网；Web→DMZ，库→内网
  • iptables：-P INPUT DROP + 放行 22/80/443
  • 关基在等保之上做重点保护，不是替代等保

冲刺薄弱清单加钉：密钥方向、等保测评不等于风险评估、日志半年先引网安法、三法分工、行三人列俩货、DMZ 在屏蔽子网、iptables 默认 DROP 再放行二十二八十与四百四十三、关基在等保之上。
