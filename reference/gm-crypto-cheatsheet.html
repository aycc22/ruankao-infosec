国密算法参数速查

冲刺补缺 · 类型 + 能核对的比特数 · 打印用 · 不推数学

SM1 的 128/128 标成机考公开回忆，不是已公开的国家标准全文。其余数字只收有 GB/T 或国密局文本撑腰的。

一、六兄弟类型

算法类型用途一句话
SM1对称分组芯片加密数据；细节未公开
SM2公钥（椭圆曲线）加密、签名、密钥交换
SM3杂凑完整性、签名前置、口令存储
SM4对称分组公开标准的数据加密
SM9标识密码身份当公钥，少交换证书
ZUC 祖冲之序列密码密钥流做流式加密

国密六兄弟类型：SM1 和 SM4 做对称分组，SM2 做公钥椭圆曲线，SM3 做杂凑，SM9 做标识密码，祖冲之做序列密码。

二、国产三件套对照

国际国产干什么
AESSM4（芯片场景可写 SM1）对称加密数据
RSA / ECCSM2公钥加密、签名、密钥交换
SHA-256SM3杂凑 / 完整性

国产三件套对照：国产 SM4 对 AES，SM2 对 RSA，SM3 对 SHA-256。

数字信封：SM4（或 SM1）加密文件 + SM2 保护对称密钥 + SM3 哈希后签名。

三、可背数字

算法数字怎么标
SM4分组 128、密钥 128GB/T 32907—2016 / GM/T 0002
SM3输出 256 比特GB/T 32905—2016；国密局 SM3 文本
SM2推荐 256 比特素数域曲线GB/T 32918.5—2017；题更爱问「椭圆曲线公钥」
ZUC128 比特初始密钥 + 128 比特 IV类型见 GB/T 33133.1 标准名；装入长度见 GM/T 0001.1
SM1分组 128、密钥 128机考公开回忆
SM9本表不背比特先认标识密码；GB/T 38635 / GM/T 0044

SM4 标准参数：SM4 分组一百二十八，密钥也是一百二十八。

SM3 输出长度：SM3 杂凑输出二百五十六，正好对标 SHA-256。

SM1 机考数字：SM1 分组和密钥，公开回忆都是 128 比特。

四、一句话用途

  • SM2 用途一句话：SM2 是椭圆曲线公钥算法，加密签名密钥交换都能干
  • SM9 标识密码：SM9 用身份当公钥，不必先交换证书
  • ZUC 序列密码：祖冲之是序列密码，密钥流按拍往外吐

题干选别选
