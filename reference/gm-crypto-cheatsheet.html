国密算法参数速查

依据教材第 3 章分类 + 国密局已核实公告标题 · 打印用 · 不推数学

一、分类秒判

算法选别选
SM1对称分组杂凑、公钥
SM2椭圆曲线公钥（非对称）对称、杂凑
SM3杂凑 / 哈希加密、分组
SM4对称分组公钥、杂凑
SM9标识密码（公钥体系）对称、杂凑
ZUC 祖冲之序列（流）密码，对称范畴杂凑、标识密码

国密算法分类：SM1 和 SM4 是对称分组，SM2 是椭圆曲线公钥，SM3 是杂凑，SM9 是标识密码，ZUC 是祖冲之序列密码。

二、对照国际

用途国际国产
大量数据保密AESSM4（及 SM1）
传密钥 / 签名RSA / ECCSM2
完整性指纹SHA-256SM3
身份当公钥标识密码SM9

国产三件套对照国际：加密签名用 SM2 对标 RSA 和 ECC，杂凑用 SM3 对标 SHA-256，对称分组用 SM4 对标 AES。

三、唯一必背数字

条目数字标签
SM1 分组长度、密钥长度128 / 128 比特机考回忆，非官方成套真题
其他 SM / ZUC 比特数本表不列教材未给，不编造

SM1 分组与密钥长度：机考公开回忆是分组一百二十八、密钥也是一百二十八。

四、数字信封（国密写法）

  • SM4 加密数据；SM2 公钥封装对称密钥；SM3 算哈希
  • 签名：SM2 私钥签、公钥验
  • 不要用 SM3 加密，也不要用 SM4 做签名

非对称密钥方向：公钥加密私钥解保密，私钥签名公钥验认证。

五、易错陷阱

  • SM3 ≠ 对称加密；哈希不可逆
  • SM2 ≠ SM4；公钥慢，只适合密钥和签名
  • SM9 ≠ 对称分组；题干写「标识密码」就选 SM9
  • ZUC ≠ 杂凑；祖冲之是序列密码
  • 不要把 SHA-256 的「256」随手套到所有 SM 上
  • 等保测评 ≠ 风险评估

六、英文词汇

ShangMi / SM-series · Symmetric block cipher · Elliptic-curve public-key · Hash / digest · Identity-based cryptography · ZUC stream cipher · Digital envelope

七、下午卷模板

先写 SM4 加密大数据 → 再写 SM2 传密钥 + 私钥签名 → 点 SM3 完整性 → 补一句密钥方向。
