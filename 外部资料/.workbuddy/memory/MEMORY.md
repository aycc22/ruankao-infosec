# 信息安全工程师备考 - 长期记忆

## 考试基本信息
- 信息安全工程师（软考中级），每年仅下半年开考一次（5月不开设）
- 自2023下半年起改为机考
- 科目：综合知识(上午75单选含5英文完形) + 应用技术(下午案例)
- 合格线：两科均≥45分且同次通过

## 真题来源可信度（重要）
- 官方（工信部教考中心/中国计算机技术职业资格网 ruankao.org.cn）从不公布完整真题
- 最可信回忆版来源：信管网 cnitpm.com、希赛网 educity.cn
- 信管网历年真题总入口：m.cnitpm.com/zhenti/aq.html（可打包下载2016至今）
- 2025下半年真题仍在持续更新中
- 警告：人人文库/原创力/优路等文档站"真题"多为模拟预测题，非真实回忆版
