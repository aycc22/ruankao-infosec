## 2024下半年真题逐题抓取（希赛网在线题库）
- 目标：`https://wangxiao.xisaiwang.com/tiku2/exam535953735.html`（2024下半年综合知识真题，考试模式，共30题）
- 交付物：`外部资料/2024下半年信息安全工程师综合知识真题_第1-30题_希赛网.html`（58KB，30题完整：题干/选项/正确答案/知识点/难度/作答统计/参考解析）
- **技术方案（可复用，已沉淀为skill）**：AppleScript + JS 接管用户已登录的 Chrome 逐题采集
  - 关键点1：需两个权限——macOS 辅助功能授权 + Chrome「查看→开发者→允许 Apple 事件中的 JavaScript」
  - 关键点2：agent-browser 会另启独立 Chrome 实例（临时配置目录），AppleScript 会连错实例导致 JS 授权失效，须先 `agent-browser close`
  - 关键点3：采集循环以 Promise 注入页面后台执行，结果挂 `window.__capResults`，Python 分批经 AppleScript 取回（单次返回体积受限）
  - 关键点4：页面结构——`.subject-content` 整题卡片、`.answerInpt` 选项radio（点击后 `.analysisAnswer` 才渲染答案解析）、答题卡 `#scantronWrap .ISpan`（data-stid）可跳题
  - 关键点5：翻页无新网络请求，渲染在页面内完成；数据经与既有汇编文档第1、2题答案(B/B)交叉验证可信
- 遗留：官方原卷75题，该页仅30题；第31-75题（含英文完形）需另找页面
