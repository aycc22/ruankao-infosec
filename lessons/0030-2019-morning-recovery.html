二、易混对比表

打印短表见 对比与参数速查卡。下面每张表后面跟同一句口诀。

主动攻击 vs 被动攻击

这是攻击分类，不要和第 10 课「主动防御 / 被动防御」混成一对。

被动攻击主动攻击
做什么窃听、流量分析，获取信息篡改、重放、伪造、中断服务
数据不改报文、不打断服务插入、修改或阻断通信
主要伤到机密性完整性、可用性，有时还有真实性
例子嗅探口令、看流量规律改报文、重放登录、DoS
口诀（主动攻击与被动攻击）：被动只偷听不改数据，主动会篡改、重放或打断服务。

异常检测 vs 误用检测

误用检测异常检测
靠什么已知攻击的特征库 / 签名正常行为基线，偏离就告警
擅长已知攻击，误报相对低有机会发现未知攻击
短板特征库里没有的认不出误报高，基线要调
题眼特征、签名、规则匹配基线、轮廓、统计偏离
口诀（异常检测与误用检测）：特征对已知是误用，基线看偏离是异常（与 第 6 课同一句）。

DAC vs MAC

DAC 自主访问控制MAC 强制访问控制
谁定规则客体的主人系统按密级 / 标签
能不能转授主人可以把权限转给别人用户改不了系统定下的密级
题眼属主授权、自行共享、可转授密级标签、强制管控、用户不能改
口诀（自主与强制访问控制）：主人自己定、可转授是自主访问控制；系统定密级、用户改不了是强制访问控制。

SSL/TLS vs IPSec

SSL/TLSIPSec
工作位置夹在传输层和应用之间网络层（IP 层）
典型用途HTTPS 网页、浏览器免客户端的 SSL VPN站点到站点或全流量隧道
常看端口TCP 443IKE 用 UDP 500，NAT 穿越常见 UDP 4500

口诀（SSL/TLS 与 IPSec）：TLS 夹在传输层和应用之间，常见于网页；IPSec 在网络层做隧道，验真找 AH、加密找 ESP。

VPN vs 网络欺骗

VPN网络欺骗
目的在公网上建加密隧道，让合法双方安全通信伪装身份或路由，让别人信错对象
典型手段隧道、加解密、身份认证IP 欺骗、ARP 欺骗、DNS 欺骗
站在哪边防护技术攻击手法
口诀（VPN 与网络欺骗）：虚拟专用网是去建加密隧道，网络欺骗是去伪装身份或路由。

CA 功能 vs PKI 组成

问的是答什么
CA 做什么签发证书、管理证书、吊销证书（信任根）。证书 = 身份 + 公钥 + CA 签名，里面没有私钥
RA 做什么受理申请、审核身份。不签发
PKI 组成至少记住 CA、RA、证书库、CRL。证书库用来发布；CRL 是吊销列表。OCSP 是在线查询吊销状态
易混「CA 的功能」≠「PKI 的全部零件」。问组成时要把 RA、证书库、CRL 一起写上
口诀（CA 功能与 PKI 组成）：认证中心负责签发和吊销，注册机构只审核；公钥基础设施还要带上证书库和吊销列表。

三、高频数字与参数

口径写在「依据」列。教材精读没写的比特数，只在有标准或协议依据时补上，并标明出处。

考点记住依据（标注）
SM3 杂凑输出 256 bit GB/T 32905—2016：杂凑值长度为 256 比特。教材精读第 3 章未列比特表；不要把 256 套到 SM2 / SM4 / SM9
DES 分组 64 bit；密钥字 64 bit，其中 56 bit 参与运算，8 bit 做奇偶校验 FIPS 46-3。有效密钥是 56，分组不是 56
3DES（TDEA） 两钥有效 112 bit（第三把等于第一把）；三钥有效 168 bit FIPS 46-3：密钥包由三把 DES 密钥组成。软考常见口径写 112 或 168。每把仍含 8 bit 校验时，两钥包常写成 128、三钥包常写成 192。新系统不要再选它
SET 常考密钥 交易数据用 DES 56 bit 会话密钥；数字信封和数字签名用 RSA 1024 bit；摘要用 SHA-1 SET 规范设计口径（RSA 1997 年 SET FAQ：加密用 56 位 DES，签名和信封用 1024 位 RSA）。软考沿用这组数。不是现行推荐，也不要套到国密或 TLS
私有地址 10.0.0.0/8；172.16.0.0–172.31.255.255（/12）；192.168.0.0/16 RFC 1918。172.32 起不再算这一段
常见端口 22 SSH；80 HTTP；443 HTTPS；53 DNS；25 SMTP；110 POP3；143 IMAP；3389 远程桌面 IANA 周知端口。本站已用补充：21 FTP、23 Telnet、123 NTP、161 SNMP；IPSec 的 IKE 为 UDP 500 / 4500
BGP 四类报文 Open 协商参数；Update 通告或撤销路由；Notification 报错并关闭；Keepalive 防止保持计时器超时 RFC 4271 的四类。另有 Route-Refresh（RFC 2918），软考常考的是这四类
口诀（国密 SM3 输出长度）：杂凑值按国标是二百五十六比特，不要套到别的 SM 算法上。
口诀（DES 密钥与分组）：分组六十四比特，密钥字里五十六比特干活、八比特做校验。
口诀（私有地址三段）：十段整段、一百七十二从十六到三十一、一百九十二点一六八。
口诀（BGP 四类报文）：Open 用来协商，Update 用来通告或撤销，Notification 报错就拆连接，Keepalive 用来保活。

四、分组模式：明文、密钥、IV 怎么变成密文

下面用同一套符号，不抄任何一年的原题数字。 P 是明文分组，C 是密文分组，K 是密钥，E 是加密函数，IV 是初始向量。 DES 的分组长度是 64 bit；别的分组算法只是把「一块多长」换成自己的分组长度，缠法不变。

ECB

明文切成一块一块。每一块单独加密：C = E(K, P)。 没有 IV，前一块密文也不参加。密钥只作用于当前明文块。 相同的明文块配同一密钥，密文块也相同。

CBC

第一块先和 IV 异或，后面每一块先和上一块密文异或，再加密： C = E(K, P XOR 上一块密文)，第一块的「上一块密文」用 IV 代替。 密钥加密的是「明文和 IV/前文密文异或之后」的结果。换 IV，第一块密文就变，后面块跟着变。

CFB

密钥不去直接加密明文。先加密上一块密文（第一块用 IV），得到一段密钥流，再和明文异或： C = P XOR E(K, 上一块密文)。 进加密函数的是 IV 或前文密文；明文只在最后一步异或。

OFB

密钥加密的是上一轮自己的输出（第一轮用 IV），得到密钥流，再和明文异或： 密钥流 = E(K, 上一轮密钥流)，C = P XOR 密钥流。 密文不送回加密函数。密钥流只跟密钥和 IV 走，不跟明文或密文走。

CTR

准备计数器（常见是一次性随机数接一个递增计数）。用密钥加密计数器，再和明文异或： C = P XOR E(K, 计数器)。 上一块密文不参加。各块可以分开算。同一密钥下，计数器不能重复。

口诀（分组模式怎么缠）：ECB 各块单独加密；CBC 先和前文密文异或再加密；CFB、OFB、CTR 都是先做出密钥流再异或明文，CFB 吃前文密文，OFB 吃自己的输出，CTR 吃计数器。

五、DES 的 S 盒：几位进、几位出

手算只追比特长度，不要求背官方八张真表。关系来自 FIPS 46-3，例子是本课自编的玩具表。

  1. 初始置换只换 64 bit 的位置，长度仍是 64，然后拆成左右各 32 bit。
  2. 右半 32 bit 做扩展置换，拉成 48 bit（有些位重复出现）。
  3. 这 48 bit 与本轮48 bit 子密钥异或，长度仍是 48。
  4. 48 bit 切成 8 段，每段 6 bit 送进一个 S 盒。
  5. 每个 S 盒：首末 2 bit 当行号（0–3），中间 4 bit 当列号（0–15），表里的数写成 4 bit。
  6. 8 个盒子输出 8×4 = 32 bit。再做一次换位，长度仍是 32，去和左半异或。

压缩发生在 S 盒：6 bit 进、4 bit 出；八个盒子一起就是 48 bit 进、32 bit 出。置换本身不改长度。

自编小例子（不是官方 S 盒，也不是真题数字）

假设只有一个玩具盒。输入 6 bit 写成 1 0 1 1 0 0。 首末两位是 1 和 0，拼成行号 10（十进制 2）。 中间四位是 0110，当作列号（十进制 6）。

口诀（DES 的 S 盒进出）：置换只换位置不改长短，S 盒六比特进、四比特出，八个盒子把四十八比特收成三十二比特。

六、动手练一练

Q1 · 攻击者只窃听通信，不修改数据，也不中断服务。这属于？
答案 B。被动攻击获取信息、不改数据。篡改、重放、打断服务才是主动攻击。不要和第 10 课的主动防御混为一谈。
Q2 · 先建立正常行为基线，偏离基线就告警。这是哪种检测？
答案 B。特征、签名、已知模式 → 误用检测。基线、轮廓、偏离 → 异常检测。
Q3 · 文件属主自己决定，并把读权限转授给同事。这是？
答案 B。主人自己定、可转授 = DAC。系统定密级、用户改不了 = MAC。
Q4 · IPSec 里负责加密的协议，以及 IPSec 所处的层，正确的是？
答案 B。AH 验真不保密，加密找 ESP。IPSec 在网络层；TLS 夹在传输层和应用之间，常见于网页。
Q5 · 在公网上为分部和总部建立加密隧道。这件事的目的是？
答案 B。VPN 的目的是加密隧道。伪装身份或路由才是网络欺骗。
Q6 · 公钥基础设施里，负责审核身份但不签发证书的是？
答案 B。CA 签发、管理、吊销。RA 只审核。PKI 组成还要加上证书库和 CRL，不能只答 CA。
Q7 · SM3 的输出长度，以及 DES 一个 S 盒的进出比特，正确的是？
答案 B。GB/T 32905：SM3 杂凑值 256 bit。FIPS 46-3：每个 S 盒 6 bit 进、4 bit 出。DES 分组是 64 bit，有效密钥是 56 bit，不要和 S 盒的进出比特搞混。
