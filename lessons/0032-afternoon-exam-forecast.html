Lesson 32 · 约 20 分钟 · 考前专项

下午卷：五类高频案例与 2026 题型预测

本课目标：把已学的第 23、28、31 课放进近十年下午卷的五个槽位；按置信度准备 2026 年 10 月这科；能手写 RSA 中间量、流量结论和场景关键词。

先看边界：这是按历年题型做的槽位预测，不是今年原题。2023 年起机考抽题，不同批次题目可以不同。官方成套解析只到 2022 年；2023、2024 用的是可交叉的考后回忆；2025 年完整下午卷在本次检索里没有对得上的公开原文。目标仍是写满得分点，拿到 45 分。场景成对写用第 23 课，iptables 的选链、状态和 NAT 用第 28 课和第 31 课。本课只排「这科更可能考哪一类」。

一、这科卷面长什么样

科目二叫应用技术（考生口头说「下午题」）。总分 75，及格 45，时长 150 分钟。 2022 年是 4 道大题；2023 年希赛考后解析写明变成 5 道。每道下面有若干小问，小问常见 2–6 分。 机考要在系统里打字：名词、命令、公式、短句都能得分，空着是 0 分。

口诀（下午卷抢分顺序）：先填名词和命令，再写原因与对策，计算题先写公式。

三、2026 年 10 月：五槽位预测

预测单位是「你会遇到哪一类写法」，不是「这五道原题」。前四槽位近十年反复出现，第五槽位按轮换准备三条备用答案。

槽位最可能的题面置信为什么这样排
1 密码手算 RSA：求 n、φ(n)、私钥 d，并判断明文能否直接加密。备用：流密码「同一密钥流用两次」；DES 填充 / S 盒 高（一定有密码题）
中（具体算法）		 2023 是 DES，2024 回忆是流密码。RSA 在 2020、2022 完整出现，间隔后最值得今晚手算一遍
2 边界设备 拓扑填空：网闸、屏蔽子网、DMZ 放网站、内网放数据库；iptables 的 filter 表、黑名单、放行 80/443、限制 SSH 源地址 高 2016 至 2023 几乎年年有。2024 回忆改成 Windows 防火墙界面。命令写法以第 28、31 课为准，考场再出就按那两课填
3 流量认读 Wireshark 过滤式；开放端口回 SYN/ACK，关闭端口回 RST；写出控制端 IP 和端口 高 2021 至 2024 连续出现，是机考最稳的「看图填空」
4 主机命令 Linux：ls -l、644、父目录 ../、哈希命令。或 Windows：eventvwr.msc、4625 表示登录失败、firewall.cpl 高 主机题年年有，Windows 与 Linux 轮换。两个模板都准备，各背 6 个词
5 场景轮换 优先准备两条：隐私「泛化 / 抑制」；Android 的 Manifest、META-INF、Content Provider。备用：SQL 注入用参数化查询 中 2022 考隐私，2021/2023/2024 都有 Android，2021/2023 有 Web。三条里能写出关键词即可
整道论述题里，应急六阶段、云计算责任、工控十六字近年整题频率低于上面五槽。若抽到，直接用 第 13 课、 第 19 课、 第 20 课 的模板按顺序写满；四场景成对写用第 23 课。等保五环节经常嵌在防火墙拓扑里，用 第 12 课的「定级、备案、建设、测评、监督」。法规名词用第 27 课。
口诀（下午卷五槽位）：密码手算防火墙令，流量主机加场景（字头：密防流主场）。

四、五个槽位怎么写才有分

槽位 1 · RSA 只记四步

公开的是 n 和 e。保密的是 p、q、φ(n)、d。加密用公钥：c = m^e mod n。签名用私钥：s = m^d mod n，验签用公钥。

  1. n = p × q
  2. φ(n) = (p − 1) × (q − 1)
  3. 找 d，使 e × d 除以 φ(n) 的余数是 1
  4. 明文 m 必须 小于 n。m ≥ n 时不能直接加密，要先分块或先做哈希

用 2020 年公开题的小数核对手感：公钥 (n, e) = (55, 3)，明文 18。

  • n = 5 × 11 = 55，φ(n) = 4 × 10 = 40
  • 3 × 27 = 81，81 除以 40 余 1，所以私钥 d = 27
  • 18³ = 5832，5832 除以 55 余 2，密文是 2
  • 回代：2^27 mod 55 = 18

2022 年公开题的规模：p=47，q=71，e=3。则 n=3337，φ(n)=3220，d=2147（因为 3×2147=6441，6441 − 2×3220=1）。用户名 admin 的十六进制是 61646d696e，这个整数远大于 3337，所以不能直接加密。

流密码备用句：同一段密钥流加密两条明文时，两条密文异或等于两条明文异或；知道一条明文就能推出另一条。字符 a 的 ASCII 是 97，二进制 01100001。

口诀（RSA 能否直接加密）：明文必须小于模数，大于等于 n 就先分块。
口诀（流密码密钥流）：同一密钥流用两次，密文相异或就露出明文差。
口诀（密钥方向）：公钥加密用私钥解，私钥签名用公钥验。

槽位 2 · 拓扑名词 + 四条命令

题眼写法
隔离强度接近物理隔离网闸（GAP）
两道过滤、中间有隔离区屏蔽子网；网站在 DMZ，数据库在内网
四道防线里的防火墙第一道保护。四道是保护、监测、响应、恢复（PDRR）
策略全是 ACCEPT黑名单：默认放行，规则负责拦截
图里的表filter。三链：进 INPUT，出 OUTPUT，转发 FORWARD
包是发给后面的服务器写在 FORWARD。发给防火墙自己才写 INPUT
/24子网掩码 255.255.255.0

命令按题干 IP 替换。默认拒绝用白名单思路：

iptables -t filter -P FORWARD DROP
iptables -A FORWARD -p tcp -d 网站IP --dport 80 -j ACCEPT
iptables -A FORWARD -p tcp -d 网站IP --dport 443 -j ACCEPT
iptables -A FORWARD -p tcp -s 运维IP -d 服务器IP --dport 22 -j ACCEPT

「不允许任何数据包进入本机」：iptables -t filter -P INPUT DROP。回程要先放行 ESTABLISHED、RELATED，网卡和 NAT 的填空以第 31 课为准。

CSF 备用（2024 单源回忆，五个功能本身是 NIST 公开框架）：识别、保护、检测、响应、恢复。相对 PDRR，CSF 多了识别。防火墙属于保护，风险评估属于识别。

口诀（iptables 黑白名单）：默认放行是黑名单，默认拒绝才是白名单。
口诀（iptables 三链）：进看 INPUT，出看 OUTPUT，穿过防火墙看 FORWARD。

槽位 3 · 报文只记三个结论

  • 开放端口：对 SYN 回 SYN/ACK
  • 关闭端口：回 RST 或 RST/ACK
  • 过滤式：ip.addr == 地址 && tcp.dstport == 端口

事件类型按破坏的属性写：打瘫服务写可用性；窃听写机密性；篡改页面写完整性。有害程序、网络攻击、信息破坏这几个类名，题干给了分类表就照表抄。

口诀（端口扫描回包）：开放端口回 SYN/ACK，关闭端口回 RST。

槽位 5 · 三条备用，各两句

  • 隐私：薪水是属性隐私。8750 显示成 5k–10k 是泛化（降低粒度）。直接抹掉是抑制。题干若自带「公开 / 内部 / 秘密 / 机密」四级，公开解析里「一般员工个人信息」常写成三级秘密数据。题干若改用《数据安全法》的一般数据、重要数据、核心数据，就按这三分法写。
  • 法规：过度采集个人信息、数据安全义务没尽到，对应《网络安全法》《数据安全法》《个人信息保护法》。
  • Android：签名在 META-INF，权限在 AndroidManifest.xml。四大组件：Activity、Service、Broadcast Receiver、Content Provider。对外暴露的 Content Provider 最容易漏数据。普通应用默认没有 root。
  • Web：SQL 注入的对策是参数化查询（预编译）。命令执行的对策是不把用户输入送进 system。配对写法：威胁一句，对策一句。
口诀（脱敏手法）：精确值改成区间叫泛化，直接抹掉字段叫抑制。
口诀（Android 泄漏点）：签名在 META-INF，权限在 Manifest，内容提供者最易漏。
口诀（SQL 注入防护）：参数化查询先编译，用户输入不当成语句。

五、考场 150 分钟怎么分配

  1. 先通读五道题的问题列表，把「填名称、填命令、填端口」的小问做完。这部分最接近 45 分里的保底分。
  2. 密码题先写 n、φ(n)、「e×d 对 φ(n) 余 1」和加密公式。算术来不及算完，过程分仍然在。
  3. 论述小问用「原因 + 对策」成对写，每条一行。写满 4 条通常就覆盖了分值。
  4. 单题超过 25 分钟还卡住，先跳到下一道的填空。五道都碰到，比一道算到底更接近及格。

六、动手练一练

Q1 · 近十年下午卷几乎每年都有的计算类题目是？
答案 B。密码手算是稳定槽位。工控、云、蜜罐会以概念出现，整道计算题的频率低得多。
Q2 · iptables 的 INPUT、FORWARD、OUTPUT 策略都是 ACCEPT，这表示？
答案 B。默认 ACCEPT = 黑名单。默认 DROP 再逐条 ACCEPT = 白名单。
Q3 · 用 RSA 直接加密整数明文 m 时，m 和模数 n 应满足？
答案 A。2022 年公开题里 admin 的整数远大于 n=3337，所以不能直接加密。
Q4 · 月薪 8750 脱敏后显示为 5k–10k，这种处理是？
答案 B。泛化是降低粒度并保留统计意义。抑制是删除或屏蔽。加密和签名是另一类机制。
Q5 · 同一段流密码密钥流加密了两条不同明文，主要风险是？
答案 A。c1 XOR c2 = m1 XOR m2。知道其中一条明文，就能推出另一条。
Q6 · 端口扫描发出 SYN 后收到 RST/ACK，通常说明？
答案 B。SYN/ACK 表示开放。RST/ACK 表示关闭或被重置拒绝。单凭这一包不能断定主机已被控制。
Q7 · Android app permissions are declared mainly in?（英文题）
答案 B。权限在 AndroidManifest.xml。META-INF 放签名。shadow 和事件查看器是主机题。
附加题（自拟小案例）· 点击展开参考写法

公司边界是屏蔽子网。网站 10.1.1.10 在 DMZ，数据库在内网。防火墙 filter 表三条链策略都是 ACCEPT。互联网要访问网站的 80 和 443；只有运维机 10.8.8.8 能 SSH 到网站。测试库里的工资 8750 被显示成 5k–10k。登录 SQL 仍用字符串拼接。

（1）结构与策略
屏蔽子网；默认 ACCEPT 是黑名单；穿过防火墙去网站的规则写在 FORWARD。

（2）规则
iptables -t filter -P FORWARD DROP
iptables -A FORWARD -p tcp -d 10.1.1.10 --dport 80 -j ACCEPT
iptables -A FORWARD -p tcp -d 10.1.1.10 --dport 443 -j ACCEPT
iptables -A FORWARD -p tcp -s 10.8.8.8 -d 10.1.1.10 --dport 22 -j ACCEPT

（3）数据与注入
8750→5k–10k 是泛化。登录拼接应改为参数化查询。再补：库留在内网、测试数据脱敏、最小权限。
