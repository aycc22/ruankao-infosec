零、先复习再开新

R1 · 数字签名的密钥方向，正确的是？
答案 B。公钥加密 → 私钥解密；私钥签名 → 公钥验签。第 3–4 课持续复习点。
R2 · 等保等级测评与网络安全风险评估是同一件事吗？
答案 B。等保测评 = 符合性判定；风险评估 = R=f(资产,威胁,脆弱性)。第 18 课易错点。
R3 · 访问控制矩阵「基于行」的实现，正确的一组是？
答案 B。基于行三人：能力、前缀、口令（贴主体）；基于列俩货：ACL、保护位（贴客体）。第 25 课间隔复习。

一、先分类型，再记数字

机考原句常先列一串名字，再问「哪一个是椭圆曲线公钥」「哪一个是杂凑」。 把六兄弟先按类型归堆，数字才不会串。

算法类型用途一句话
SM1 对称分组密码 芯片里加密数据本体；算法细节未公开
SM2 公钥密码（椭圆曲线） 加密、数字签名、密钥交换
SM3 杂凑（哈希）算法 完整性校验、签名前置、口令存储
SM4 对称分组密码 公开标准的数据加密（对标 AES）
SM9 标识密码（身份即公钥） 用身份标识当公钥，少跑一套证书
ZUC
祖冲之		 序列密码（流密码） 按拍吐密钥流，做流式加解密
口诀（国密六兄弟类型）：SM1 和 SM4 做对称分组，SM2 做公钥椭圆曲线，SM3 做杂凑，SM9 做标识密码，祖冲之做序列密码。
易错：SM1 和 SM4 都是对称分组，不要把 SM4 当成哈希；SM2 是公钥不是杂凑；ZUC 是序列不是分组。

二、国产三件套 vs AES / RSA / SHA-256

第 3 课口诀「国产 SM2 · SM3 · SM4」就是这套对照。下午卷写「用国密替换国际算法」时，按行填：

要解决国际常用国产对应别填成
加密大量数据 AES（对称分组） SM4（公开标准）；政务芯片场景也可能写 SM1 SM2、SM3
签名 / 传密钥 / 公钥加密 RSA 或 ECC SM2（椭圆曲线公钥） SM4、SM3
完整性 / 指纹 SHA-256 SM3（杂凑输出 256 比特） SM4、MD5

数字信封思路不变：对称加密数据，非对称传那把对称密钥——国密写法就是 SM4（或 SM1）加密文件，SM2 保护会话密钥，SM3 做哈希再签名。

口诀（国产三件套对照）：国产 SM4 对 AES，SM2 对 RSA，SM3 对 SHA-256。
SM9 不是三件套成员：它是标识密码，用邮箱、身份证号这类身份当公钥，减少证书交换；不要把它填进「替代 AES」那一格。

三、只背能核对来源的比特数

数字题最容易编造。本课只记下面有出处的；没有国家标准或机考公开回忆撑腰的，考试时宁可不写。

算法可背数字出处（怎么标）
SM4 分组 128 比特，密钥 128 比特 GB/T 32907—2016；行业标准 GM/T 0002—2012
SM3 杂凑输出 256 比特（32 字节） GB/T 32905—2016；国密局 SM3 文本写明输出 256 比特。对标 SHA-256，不是 MD5 的 128
SM2 推荐曲线为素数域 256 比特椭圆曲线 GB/T 32918.5—2017 参数定义。题更爱问「椭圆曲线公钥」，不一定问比特
ZUC 常用描述：128 比特初始密钥 + 128 比特初始向量 类型以 GB/T 33133.1—2016 标准名「序列密码」为准；密钥装入长度见 GM/T 0001.1 算法描述
SM1 分组 128 比特，密钥 128 比特 机考公开回忆（见考点分布页），不是已公开的国家标准全文。算法细节未公开、常以芯片实现
SM9 本课不背比特数 先认类型：GB/T 38635.1—2020 英文名 Identity-based；行业标准 GM/T 0044
口诀（SM4 标准参数）：SM4 分组一百二十八，密钥也是一百二十八。
口诀（SM3 输出长度）：SM3 杂凑输出二百五十六，正好对标 SHA-256。
口诀（SM1 机考数字）：SM1 分组和密钥，公开回忆都是 128 比特。
SM1 的 128/128 在课里、口诀卡、速查卡一律标成机考公开回忆。计分模考仍以 2018–2022 官方试题分析为准；这条用来校准「机考爱问这个数字」。

四、机考原句怎么认

对照 考点分布 的两类高频问法：

  1. 点名类型：「属于椭圆曲线公钥密码算法的是」→ 选 SM2（不要选 SM1/SM3/SM4）。
  2. 点名数字：「SM1 是对称分组密码，分组长度和密钥长度分别是」→ 公开回忆选项是 128 和 128。

英文题可能写 block cipher / public-key / hash / stream cipher / identity-based。 先译成中文类型，再对号入座。

口诀（SM2 用途一句话）：SM2 是椭圆曲线公钥算法，加密签名密钥交换都能干。
口诀（SM9 标识密码）：SM9 用身份当公钥，不必先交换证书。
口诀（ZUC 序列密码）：祖冲之是序列密码，密钥流按拍往外吐。

五、动手练一练

Q1 · 下列属于椭圆曲线公钥密码算法的是？
答案 C。SM2 = 椭圆曲线公钥；SM1/SM4 = 对称分组；SM3 = 杂凑。2023–2025 机考同型问法。
Q2 · SM1 是对称分组密码。机考公开回忆中，其分组长度和密钥长度分别是？
答案 D。标成机考公开回忆：分组与密钥均为 128 比特。不是已公开的国家标准全文，答题时仍按回忆口径选 128/128。
Q3 · SM3 杂凑算法的输出长度是？
答案 C。GB/T 32905 与国密局 SM3 文本：输出 256 比特。不要和 MD5 的 128 搞混。
Q4 · 用国密替换 AES、RSA、SHA-256，正确对应是？
答案 B。SM4 对 AES（对称分组），SM2 对 RSA（公钥），SM3 对 SHA-256（杂凑）。
Q5 · 下列属于标识密码算法的是？
答案 C。SM9 = 标识密码（identity-based）：身份当公钥。标准见 GB/T 38635、GM/T 0044。
Q6 · 祖冲之（ZUC）算法属于哪一类？
答案 D。GB/T 33133 / GM/T 0001 标准名就是「序列密码」。不要选成分组或公钥。
Q7 · SM4 is best classified as which of the following?（英文题）
答案 C。SM4 = symmetric block cipher。Hash 是 SM3；public-key 是 SM2；identity-based 是 SM9。
附加题（下午卷风格）· 点击展开答案

某政务系统原用 AES 加密业务文件、RSA 做签名与密钥封装、SHA-256 做完整性校验。现要求改用商用密码，并说明 SM1 与 SM4、SM9 与 SM2 各怎么选。请：（1）给出替换方案；（2）点出至少 3 条易错。

（1）替换方案
· 加密数据本体：SM4（公开标准对称分组，对标 AES）。若题干强调芯片/未公开算法，可写 SM1（同为对称分组）。
· 签名与密钥封装：SM2（椭圆曲线公钥，对标 RSA/ECC）；数字信封 = SM4 加密文件 + SM2 保护对称密钥。
· 完整性：SM3（输出 256 比特，对标 SHA-256）；签名流程仍是「先哈希再私钥签」。
· 若要「身份即公钥、少部署证书」：补 SM9 标识密码，不是拿 SM9 去替 AES。
· 流式链路加密可写 ZUC 序列密码，不要写成杂凑。

（2）易错
· 密钥方向不变：公钥加密 → 私钥解密；私钥签名 → 公钥验签。
· SM1 的 128/128 按机考公开回忆答，不把它写成已公开国标全文。
· 等保测评 ≠ 风险评估；写合规条款时不要把测评当风险评估交。
模板：先填三件套对照 → 再点类型（分组/公钥/杂凑/标识/序列）→ 数字只写有出处的。
