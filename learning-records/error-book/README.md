## 错因三选一

每行除五栏外，再贴一个标签，只能选一个：

| 标签 | 何时用 |
|------|--------|
| 概念混淆 | 两个名词都会，但放反了 |
| 参数记忆 | 概念对，数字、端口、报文类型错了 |
| 审题问题 | 知识点会，看错主语、否定词或「哪一项不属于」 |

口诀（**错因三标签**）：概念放反贴混淆，数字端口贴参数，看错主语或否定词就贴审题。

## 五栏 + 错因

| 栏 | 写什么 |
|----|--------|
| 题号 | 卷别 + 印刷题号，例如「2019 上午 12」。没有把握就空着 |
| 错选 | 当时选的项，加半句为什么会选 |
| 正解 | 正确项 + 半句理由。理由用自己的话，不粘贴原题 |
| 对应课或对比表锚点 | 第 N 课，或第 30 课对比表锚点（如 `#dac-mac`） |
| 口诀锚点 | `reference/mnemonics.html` 里的课号锚点 |
| 错因 | 概念混淆 / 参数记忆 / 审题问题 |

五栏缺一栏不算回收。错因不替代五栏。
