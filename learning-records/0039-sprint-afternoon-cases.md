# 0039：下午卷风格案例练习（3 案例 × 3 小题 · 9/9）

2026-10-18（Asia/Shanghai）对话练习（导师安然）。来源 `question-bank/sprint.html` §下午卷风格案例（case-1、case-2、case-3）。形式：对话点选控件，一小题一问。得分 **9/9** 全对（3 案例 × 3 小题）。

## 案例 1 · 市政务网站被注入（拓扑 + Web）（3/3）

1 ✓ 风险：Web、应用、库同网段并对公网暴露 → 拖库、横向移动；输入单引号出现数据库语法错误回显 → 注入探测；把一次漏洞扫描当成等保测评 → 符合性未判定，监管与备案要求落空。
2 ✓ 措施：Web 放 DMZ、库放内网；入口串联 WAF；参数化查询并关闭详细报错；管理口 SSH + ACL。
3 ✓ 漏洞扫描找已知漏洞；风险评估算 R；等保测评按 GB/T 28448 判定是否符合相应等级。三者目的不同，不能互相替代。

**错题**：无。

## 案例 2 · 离散制造产线远程运维（工控）（3/3）

1 ✓ 优先序：可用性高于完整性，完整性高于机密性。停线、误动作的后果通常大于工艺数据被看。
2 ✓ 措施：工控与办公网、互联网分区隔离；关闭 Telnet/FTP，确需远程走 VPN；改默认口令并做白名单；边界用工业防火墙或网闸。
3 ✓ 等保：通用要求叠加**工业控制系统安全扩展**。等级测评看符合性，不等于风险评估。

**错题**：无。

## 案例 3 · 政务 SaaS 上云（责任共担 + 合规）（3/3）

题干为公有云 IaaS：云商提供虚拟机，局方安装操作系统和业务。

1 ✓ IaaS 下局方仍管：客户操作系统补丁与加固；应用与数据、账号权限；业务日志与备份策略；上云配置（安全组 / VPC）。
2 ✓ 多租户：共驻泄露、虚拟机逃逸 → 租户隔离并镜像加固；安全组过宽 → 最小权限；快照残留、账号滥用 → 加密 + KMS、安全擦除。
3 ✓ 风险评估算风险；等保测评做符合性。云上系统在通用要求上叠加**云计算安全扩展**。

**错题**：无。

## 口诀锚点

- 拓扑部署：Web 放 DMZ，库放内网；管理口走 SSH，再配 ACL。
- SQL 注入防护：简单过滤挡不住注入，参数化查询才可靠；详细报错回显便于探测，要关掉。
- WAF 部署要点：WAF 串联 Web 入口，规则语义拦注入。
- 工控安全需求优先序：先保能用再保完整，机密性排在最后（可用＞完整＞机密）。
- 工控远程访问原则：公网高危服务先关掉，确需远程走 VPN。
- 等保工控扩展要求：通用不够再加工控，分区隔离要到位。
- 云安全责任共担：云上安全大家扛，厂商管底座用户管业务。IaaS 下客户操作系统、应用、数据、账号、日志备份和安全组仍归局方。
- 等保云扩展要求：通用不够再加云扩，镜像快照要管住。
- 等保测评与风险评估：测评看符合性，评估看风险，两套不是同一件事。漏扫只找已知漏洞，不能代替测评。
- 下午卷案例答题模板：先判场景列风险，对策成对写一行，合规扩展别漏项，监测应急来收束。
