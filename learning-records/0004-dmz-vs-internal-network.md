# 0004：DMZ 与内网位置混淆（第 5 课反馈）

用户在堡垒主机 / DMZ 概念澄清后自测：Q1「堡垒主机=一台机器」✓；Q2「DMZ 出现在屏蔽子网」✓；Q3「外网访问官网流量最先到达内网」✗——正确应为 **DMZ**。

**混淆点**：把「公司官网」等同于「内网资源」。官网是对公众开放的 Web 服务器，按标准架构应部署在 **DMZ 隔离区**，而非内网。内网放数据库、办公系统、文件服务器等不直接对外的资产；外网 → 外路由器 → **DMZ（Web）** → 内路由器 → 内网。

**Implications**：后续题先问「这个服务对谁开放？」——对公网开放 → DMZ；仅内部使用 → 内网。可与「防外不防内」/firewall 局限一并复习。
