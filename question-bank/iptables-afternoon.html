单选

1 · 策略为 -P FORWARD DROP。规则是 -A FORWARD -p tcp -d 192.168.10.8 --dport 80 -j ACCEPT。效果是？
答案 B。-d 限制目的地址，--dport 80 限制目的端口，链是 FORWARD。其余转发由默认 DROP 兜住。本机服务看 INPUT；改源地址看 nat 的 SNAT 或 MASQUERADE。
2 · 关于 -o（出去的网卡），手册允许写在哪些链上？
答案 B。iptables(8)：-o 用于 FORWARD、OUTPUT、POSTROUTING。-i 才用于 INPUT、FORWARD、PREROUTING。D 把 -i 的链套到了 -o 上。
3 · 按 iptables-extensions 的连接状态，NEW 指的是？
答案 B。NEW 是新连接或尚未双向看到包。ESTABLISHED 才是已经双向看到包。RELATED 是挂在已有连接上的相关流。INVALID 是对不上已知连接。
4 · 公网地址固定。内网出去时把源地址改成这个固定地址，填空优先写？
答案 A。改源地址、包要离开本机，优先填 POSTROUTING。地址固定用 SNAT；地址会变才用 MASQUERADE。DNAT 改的是目的地址，常见位置是 PREROUTING。
5 · 先执行 iptables -A FORWARD -j DROP，再追加一条放行 TCP 80。转发的 80 端口会怎样？
答案 B。-A 追加到链尾，先追加的 DROP 没有匹配条件，所有走到它的转发包都被丢掉，后面的 ACCEPT 不会再生效。改默认策略要用 -P，插到链头要用 -I。
6 · 门户主机只对本机开放 SSH 与 HTTPS，链应选？
答案 A。别人访问这台机器上的 22/443，目的是本机套接字，写 INPUT。FORWARD 用于路过转发。POSTROUTING / PREROUTING 是 nat 改地址的位置，不能代替本机放行。

案例 · 县图书馆边界防火墙（3 小题）

自编场景

县图书馆有一台 Linux 边界防火墙。eth0 接外网，eth1 接 DMZ，门户网站地址 172.16.8.10，只提供 HTTPS（TCP 443）。eth2 接内网 172.16.9.0/24，借阅库不允许外网直连。包穿过防火墙到达门户，不进入防火墙自己的网站进程。

请先自己写，再展开对照。

  1. 写出一条规则：外网访问门户的 TCP 443 新连接予以放行。要写出链、进来的网卡、出去的网卡、目的地址、目的端口和 NEW。
  2. 默认策略怎么写，才能让「外网到内网」在没有单独 ACCEPT 时也被拒绝？再写一条放行已建立和相关回程的规则。
  3. 下面三条命令各做什么：哪条改目的地址，哪条改源地址，哪条只做过滤转发？
    iptables -t nat -A PREROUTING -i eth0 -p tcp --dport 443 -j DNAT --to-destination 172.16.8.10:443
    iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
    iptables -A FORWARD -i eth0 -o eth1 -p tcp -d 172.16.8.10 --dport 443 -m state --state NEW -j ACCEPT
展开参考要点
  • 小题 1：链用 FORWARD。示例：iptables -A FORWARD -i eth0 -o eth1 -p tcp -d 172.16.8.10 --dport 443 -m state --state NEW -j ACCEPT。网卡名以题干为准。
  • 小题 2：iptables -P FORWARD DROP。外网到内网没有 ACCEPT，链尾由默认 DROP 兜住。iptables -A FORWARD -m state --state ESTABLISHED,RELATED -j ACCEPT 放行回程。这条回程要写在「匹配全部的 DROP」之前；默认策略本身可以先设好。
  • 小题 3：第一条 nat PREROUTING + DNAT，改目的地址。第二条 nat POSTROUTING + MASQUERADE，出口地址会变时改源地址。第三条 filter 的 FORWARD（没写 -t 就是 filter），只放行转发，不改地址。
  • 口诀：改目的地址用 DNAT，写在 nat 表的 PREROUTING；改源地址用 SNAT 或 MASQUERADE，写在 nat 表的 POSTROUTING；出口地址会变时用 MASQUERADE。
