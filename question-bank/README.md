# 题库（自编练习）

**题库拥有者：aycc345**

- 结构化字段见 `manifest.json`：`owner: aycc345`
- 本目录托管在课程仓库 `aycc22/ruankao-infosec` 的 `question-bank/`，便于 GitHub Pages 浏览；**托管仓库账号（aycc22）不等于题库拥有者**。

独立于 `lessons/` 的刷题区。题目为自编练习，**不是**官方软考真题。

| 文件 | 用途 |
|------|------|
| `index.html` | 题库首页 / 入口说明 |
| `sprint.html` | 综合冲刺：60 道上午卷风格单选 + 3 道下午卷风格简答 |
| `manifest.json` | 题库元数据（拥有者、托管位置、非真题声明） |
| `_gen.py` | 题目数据与生成器（改题后运行 `python3 _gen.py`） |

课内小测仍只在各课 HTML 里；学完新课后的结业测仍在 Cursor 对话里做。
